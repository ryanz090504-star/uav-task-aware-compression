# Contributing

v0.1.0 freezes its scientific definitions and evidence. Propose new methods as explicitly versioned experiments; do not overwrite frozen results or change thresholds to match a claim.

Before submitting a code change, install the package and CPU PyTorch, run `python -m unittest discover -s tests -v`, and run the synthetic heuristic demo shown in [README](README.md). Add a focused regression for a meaningful defect. No dataset or withheld checkpoint is needed for CI.

Do not submit VisDrone images, labels, crops, GT-containing detections, model checkpoints, credentials, generated outputs or local paths. Keep locally generated research artifacts outside the repository. Report licensing/provenance uncertainties before proposing third-party material.

Describe behavior, validation and scientific impact in contributions. Ownership and the applicable project/dependency licenses require review; this document does not invent contributor rights or add terms to LICENSE.
